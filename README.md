# Tailandia
🇹🇭 Atrativos Turísticos da Tailândia
📌 Sobre o projeto

Este projeto consiste em um site sobre atrativos turísticos da Tailândia, desenvolvido como atividade de desenvolvimento web.

O site apresenta informações, imagens e curiosidades sobre alguns dos principais destinos turísticos do país, utilizando uma interface visual inspirada na cultura e nas paisagens tailandesas.

🎯 Objetivo

O objetivo do projeto é apresentar informações turísticas sobre a Tailândia e, ao mesmo tempo, aplicar conhecimentos de HTML e CSS, como criação de páginas, organização de conteúdo, imagens, vídeos, links e estilização de elementos.

🗺️ Conteúdo do site

O site possui uma página inicial com acesso às seguintes seções:

Curiosidades sobre a Tailândia
O cumprimento tradicional WAI;
O nome oficial/extenso de Bangkok;
Vídeo relacionado à pronúncia.
Templo Branco de Chiang Rai (Wat Rong Khun)
História e características do templo;
Localização;
Informações sobre sua construção e seu criador.
Grand Palace
História do Grande Palácio de Bangkok;
Wat Phra Kaew;
Buda de Esmeralda;
Informações históricas e culturais.
Ilhas Phi Phi
Localização;
Características das ilhas;
Phi Phi Don e Phi Phi Leh;
Principais atividades turísticas.
💻 Tecnologias utilizadas
HTML5 — estrutura e organização das páginas;
CSS3 — estilização, layout, cores, fontes e imagens;
Google Fonts — utilização da fonte Tangerine;
Flexbox e CSS Grid — organização dos elementos da página.

🌐 Como executar
Baixe ou clone este repositório.
Extraia os arquivos do projeto.
Abra a pasta ativ04B.
Abra o arquivo index.html em um navegador.

Não é necessário instalar nenhuma dependência ou programa adicional para executar o site.

🎨 Características

O projeto utiliza:

Cards para apresentar os pontos turísticos;
Imagens relacionadas à Tailândia;
Vídeo incorporado em uma das páginas;
Links para navegação entre as páginas;
Layout organizado com CSS Grid e Flexbox;
Imagem de fundo no cabeçalho;
Fonte personalizada através do Google Fonts;
Botão de retorno à página inicial nas páginas internas.
